# Case Study Workflow (SOP_CASE_STUDY)

**Use when:** Conducting and writing up case study research.

---

## Step 1: Case Selection

Define case parameters:

- Unit of analysis
- Case boundaries
- Selection rationale (typical, deviant, critical, etc.)
- Single vs. multiple case design

---

## Step 2: Case Structure

Design case study approach:

### Single Case Design

- In-depth analysis
- Theory testing or building
- Unique/revelatory case

### Multiple Case Design

- Cross-case comparison
- Replication logic
- Pattern matching

---

## Step 3: Data Collection

Gather case evidence:

- Documents
- Archival records
- Interviews (if applicable)
- Observations
- Artifacts

---

## Step 4: Case Description

Write rich description:

- Context
- History/timeline
- Key actors
- Events
- Outcomes

---

## Step 5: Analysis

Apply analytical technique:

- Pattern matching
- Explanation building
- Time-series analysis
- Logic models
- Cross-case synthesis

---

## Step 6: Thematic Coding

For qualitative analysis:

- Open coding
- Axial coding
- Selective coding
- Theme development

---

## Step 7: Case Report Writing

Structure the case study paper:

1. Introduction
2. Literature Review
3. Methodology
4. Case Description
5. Analysis & Findings
6. Discussion
7. Conclusion
