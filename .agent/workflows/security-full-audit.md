# Full Security Audit Workflow

**Use when:** Conducting a comprehensive security assessment covering risk simulation, defense architecture, protocol verification, and ethical/regulatory compliance.

> ⚠️ **This is a mega-workflow.** It chains 4 security SOPs into a complete audit pipeline.

---

## Phase 1: Cyber Risk Simulation (SOP_CYBER_RISK_SIM)

> **4 Agents**

1. `SaaSShadowITCartographer` — Map all assets and shadow IT
2. `AdversarialAttackSimulator` — Run MITRE ATT&CK kill chains
3. `ThreatModeler` — STRIDE/DREAD threat modeling
4. `SecurityStandardsChecker` — NIST/ISO/CIS compliance mapping

**Output:** Asset map, attack paths, threat model, compliance gaps

---

## Phase 2: Defense Architecture (SOP_DEFENSE_ARCH)

> **4 Agents**

1. `CyberSecurityArchitect` — Design defense-in-depth
2. `MinViableSecurityArchitect` — Right-size for organization
3. `IncidentReadinessPlaybookGenerator` — Create IR playbooks
4. `RegulatoryComplianceAuditor` — Verify regulatory compliance

**Output:** Security architecture, IR playbooks, compliance documentation

---

## Phase 3: Protocol Security (SOP_PROTOCOL_SECURITY_AUDIT)

> **4 Agents**

1. `ProtocolNetworkSemanticsVerifier` — RFC compliance verification
2. `CryptoProtocolVerifier` — Cryptographic protocol analysis
3. `NetworkTrafficModeler` — Traffic pattern analysis
4. `ThreatModeler` — Protocol-specific threats

**Output:** Protocol audit report, crypto assessment, traffic analysis

---

## Phase 4: Ethics & Privacy (SOP_ETHICAL_AUDIT)

> **4 Agents**

1. `EthicalComplianceGuard` — Ethics screening
2. `DataPrivacyOfficer` — GDPR/HIPAA audit
3. `RedTeamEthicsDualUseGuard` — Dual-use assessment
4. `RegulatoryComplianceAuditor` — Final regulatory check

**Output:** Ethics report, privacy audit, dual-use assessment

---

## Total Agent Count: 16 agents across 4 phases

## Comprehensive Security Report

Final deliverable combines all phases into:

1. **Executive Summary** — Risk posture overview
2. **Asset Inventory** — Complete IT landscape
3. **Threat Assessment** — Prioritized risk matrix
4. **Defense Architecture** — Recommended controls
5. **Protocol Analysis** — Communication security
6. **Compliance Status** — Regulatory alignment
7. **Remediation Roadmap** — Prioritized action plan
