# Evaluation Design and Claim Boundaries Review Package

This directory contains the anonymized evidence package for the manuscript subsection titled **Evaluation Design and Claim Boundaries**. It is designed for blind peer review and provides a compact, reviewer-facing trail for the study's early-stage artifact evaluation posture, explicit non-claims, and bounded reproducibility stance.

## Package Purpose

The package supports four reviewer-facing questions:

1. Why the study uses an early-stage design-oriented evaluation posture.
2. What the artifact is claimed to do.
3. What the artifact is explicitly **not** claimed to do.
4. Why the paper treats the framework as a literature-grounded decision heuristic rather than an empirically confirmed universal model.

## Included Files

- `evidence_manifest.json` — machine-readable inventory of the package
- `evaluation_note.md` — concise explanation of the evaluation posture and non-claims
- `claim_boundaries_map.md` — mapping from manuscript claims to supporting evidence sources
- `design_science_audit_excerpt.md` — reviewer-safe excerpt showing how the manuscript's design-science citations support the stated evaluation posture

## Anonymity Note

This package intentionally omits author-identifying information, workstation paths, and non-review operational artifacts. File references are package-local so reviewers can inspect the evidence without exposure to unrelated repository materials.

## How to Use This Package

1. Start with `evaluation_note.md` for the high-level evaluation logic.
2. Use `claim_boundaries_map.md` to inspect the paper's positive claims and explicit non-claims.
3. Use `design_science_audit_excerpt.md` to verify the design-science grounding for the stated evaluation posture.
4. Use `evidence_manifest.json` to verify the package contents and file roles.
