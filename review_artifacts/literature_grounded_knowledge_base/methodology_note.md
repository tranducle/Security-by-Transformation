# Methodology Note

## Corpus Refinement

This review package documents the retained evidence base used to support the manuscript's literature-grounded knowledge base section.

- Initial deduplicated literature pool: **216** records
- Shortlist reviewed after narrowing: **40** records
- Core shortlist retained for framework construction: **21** records

The retained studies follow the rule below:

> Keep papers scoring >= 10 on SME + digital transformation + security/capability/prioritization heuristics, plus a small manually curated set of strategic background papers.

## Screening Signals

Retention prioritized papers that contributed to one or more of the following signals:

- SME focus
- digital transformation relevance
- cybersecurity or security framing
- capability, readiness, or maturity language
- resilience and continuity relevance
- resource, governance, or prioritization constraints

## Theme Assignment Logic

Each retained paper was annotated against the manuscript's five guiding themes:

1. SME digital transformation
2. readiness and maturity
3. cybersecurity implications
4. resilience and continuity
5. resource or governance constraints

Theme assignments are intentionally inclusive rather than exclusive. A paper may support multiple themes when its abstract, rationale, or selection metadata contributes to more than one aspect of the framework backdrop.

## Package Scope

This package is a **reviewer-facing evidence bundle**, not the full project repository. It is designed to allow verification of the manuscript's literature-grounded framing without exposing project-internal working files, local paths, or author-identifying metadata.
