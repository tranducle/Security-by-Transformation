📋 20 Core Use Cases — Step-by-Step
End-to-End
📝 UC1: From Zero to Research Paper
No topic yet? Go from blank slate to submission-ready manuscript.
  1. /idea-discovery — AI scouts trending topics, generates novel ideas
  2. /literature-search — Searches 4 academic databases (OpenAlex, Scopus, Semantic Scholar, Google Scholar)
  3. /gap-analysis — Maps research gaps across collected literature
  4. /research-plan — Creates WBS with milestones, budget, timeline
  5. /paper-outline — Structures paper with sections from literature
  6. /write-paper — Full manuscript draft with 10+ agents
  7. /harden-paper — 10-agent hardening pipeline
  8. /paper-to-submission — Final polish: citation audit + BibTeX optimization
💡 Shortcut: /full-research-cycle chains all of these automatically
Research & Discovery
📚 UC2: Comprehensive Literature Review
Systematic search, synthesis, and gap identification across academic databases.
  1. /literature-search — Auto-queries OpenAlex → Scopus → Google Scholar → Semantic Scholar
  2. System deduplicates and ranks papers by relevance
  3. /synthesize — DeepSynthesizer combines findings into coherent narrative
  4. /gap-analysis — GapScout identifies methodological, contextual, empirical gaps
  5. /novelty-check — PriorArtNoveltyScanner verifies your idea is novel
Output: literature_synthesis.md gap_analysis.md references.bib
Research & Discovery
🔬 UC3: Systematic Review (PRISMA)
Full PRISMA-compliant SLR with protocol, screening, and quality assessment.
  1. /systematic-review — SLRProtocolDroid creates PRISMA protocol
  2. Define inclusion/exclusion criteria, databases, date ranges
  3. System searches all 4 databases with structured queries
  4. Title/abstract screening → Full-text screening
  5. Quality assessment using CASP/JBI checklists
  6. Data extraction and synthesis with PRISMA flow diagram
Output: PRISMA_flow.md slr_protocol.md quality_assessment.md
Methodology
⚗️ UC4: Quantitative Experiment Pipeline
Design, execute, analyze, and visualize experiments end-to-end.
  1. /experiment-design — MethodologyExperimentDesigner creates experiment protocol
  2. /data-preprocessing — DataPreprocessingEngineer cleans and prepares data
  3. /auto-experiment — AutoExperimentRunner executes experiments autonomously
  4. Statistical analysis: t-tests, ANOVA, correlation, regression
  5. /figures — FigureGenerator creates publication-ready charts
💡 Shortcut: /quant-experiment runs the full SOP pipeline
Writing & Quality
🛡️ UC5: Paper Hardening Before Submission
10-agent pipeline to strengthen logic, evidence, novelty, and reviewer-readiness.
  1. /harden-paper — Launches SOP_PAPER_HARDENING
  2. PeerReviewer → initial assessment + score
  3. HarshReviewer → adversarial critique (Reviewer #2 mode)
  4. FeasibilityRigorSoundnessChecker → methodology audit
  5. BaselineBenchmarkNoveltyDefender → baseline comparison verification
  6. ReviewerStrategist → generates rebuttal strategies
  7. /citation-audit → verify all references
  8. Apply revisions to manuscript
Output: hardening_report.md rebuttal_strategy.md
Security & Risk

⚡ LangGraph Pipeline — CLI Guide

The LangGraph pipeline is your programmatic interface to the agent system. Use it for automation, batch processing, health checks, and integration into scripts.

Note: For daily research work, the Antigravity + /init approach is recommended. LangGraph CLI is for power users and automation.

🚀 Run Full Pipeline
python src/langgraph/run.py "find literature on cybersecurity"

Runs the complete 15-node pipeline: feedback detection → prompt optimization → routing → agent loading → tool execution → quality validation → output

📋 JSON Output (for AI)
python -m src.langgraph.cli --json "threat model"

Returns structured JSON with routing info, agent context, tools, and response — ideal for scripting and integration

⚡ Quick Route (Agent Name Only)
python src/langgraph/run.py --quick "write methodology"

Returns just the agent name — fast routing without full pipeline execution

💉 Prompt Injection
python src/langgraph/run.py --inject "brainstorm ideas"

Returns the full system prompt for the routed agent — use to inject into other AI tools

💡 When to use LangGraph CLI vs. Antigravity:
• Daily research: Use Antigravity + /init + natural language (Claude IS the brain)

• Scripting: Use --quick in bash scripts for fast routing decisions
💡 Pro Tips for Power Users
🧠
Use /memory Regularly
Run /memory every few sessions to checkpoint context. Prevents AI from forgetting project state across conversations. Essential for long projects.
🔗
Chain Workflows
Combine workflows in sequence: /literature-search → /gap-analysis → /novelty-check. Each builds on the previous output automatically.
🤖
Just Talk Naturally
You don't need to know agent names. Say "find papers about adversarial ML" and the MasterOrchestrator routes to the right agents automatically.
📊
Track Progress
Use /progress-check and /daily-summary to see where you are. /sync updates all tracking files simultaneously.
🛡️
Always Harden Before Submit
Never submit without running /harden-paper. It catches 80%+ of Reviewer #2 objections before they happen. Use /cyber-paper-hardening for security papers.
🔄
Self-Repair When Stuck
If an agent gives bad output, run /self-repair. The AgentSystemArchitect diagnoses and fixes the agent's prompt automatically.
📐
Verify Math Twice
Use /verify-math which runs both SymPy (local, free) AND Wolfram Alpha (cloud) for cross-verification. Never trust one source alone.
📋
Use Compound Workflows
For big tasks, use compound workflows like /full-research-cycle (17+ agents) or /paper-to-submission (15+ agents) to automate multi-step processes.
🎯
Scope Early with /research-plan
Run /research-plan before diving in. The ResearchPlanGenerator creates a detailed WBS with task assignments, preventing scope creep.
